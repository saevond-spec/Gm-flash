# Sprite #1878 — First-bid coaching protocol

Status: operator playbook; not a completed bid or trained model.

## Easy-first selection
Prefer small standalone scalar CSV cleanup or integer-cent arithmetic reconciliation jobs with explicit inputs, outputs, acceptance checks, and no external credentials or paid dependencies. Prefer 1–4 hour scope and a verified quote of $20–$50 USD under the existing authorized limits. Never infer currency or units from ambiguous price fields. Do not select simulated or zero-compensation jobs. Missing evidence is unknown, not a pass. Avoid tasks requiring professional credentials, physical work, unsupported software, or specialist human participation.

## Coach-assisted first bid
1. Verify the marketplace ID, live open status, fee, compensation and absence of a previous Sprite bid.
2. Review the exact acceptance requirements inside the dedicated task environment, never in the Sprite control plane. Use independently verified isolated execution capability and synthetic rehearsal evidence. Retain no customer brief, attachment, proposal, contact or credentials in shared systems.
3. Estimate the effort and fixed price; verify zero additional spend and the actual delivery deadline.
4. Write a concise buyer-specific approach, concrete deliverables, verification procedure, realistic timeline, assumptions and exclusions. Use the buyer's language where appropriate. Never claim already completed tests or prior commercial outcomes without evidence.
5. Use the existing guarded dispatcher and independently verified expiring readiness attestation. Submit once; reconcile any uncertain response using official bid outcomes before another attempt.
6. Verify bid ID, problem ID, Sprite agent ID, amount and upstream status. Distinguish attempted, received, selected, delivered, accepted and settled.

## Learn, do not memorize customer data
Collect only authorized non-sensitive scalar outcome counts and reason categories within Sprite's own project. Use marketplace-provided feedback after a real bid, not invented feedback. Review failed eligibility decisions separately from actual buyer rejections. Retain only generalized, non-customer-specific engineering lessons. Never import other agents' artifacts, raw outcomes or customer material. Do not treat historical bid values as earnings or transferable reputation.
